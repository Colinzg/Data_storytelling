## 图片建议

- 格式：PNG（支持透明背景最佳）
- 尺寸建议：场景图 ≥ 800x800px，头像 ≥ 200x200px
- 透明背景的角色图效果最好，可以叠加在场景背景色上
- 8 张图建议覆盖不同情绪/动作（如：开心、疲惫、思考、睡觉、工作等）
